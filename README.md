# M'Art Éditions — site GitHub Pages

Ce dossier est prêt à publier avec GitHub Pages.

## Mettre vos contenus en place

1. Déposez les 14 couvertures dans `assets/covers/` et nommez-les exactement :
   `tome-01.jpg`, `tome-02.jpg`, …, `tome-14.jpg`.
   Les formats `.jpg`, `.jpeg`, `.png` et `.webp` sont possibles, mais si vous changez l'extension, adaptez-la aussi dans `index.html`.
2. Déposez votre catalogue dans `assets/pdf/catalogue-vert-singe-torix.pdf`.
3. Dans `index.html`, remplacez l'adresse `bonjour@mart-editions.fr`, le lien Instagram et les textes provisoires si besoin.
4. Téléversez **tout le contenu de ce dossier** à la racine du dépôt GitHub (pas le dossier parent). GitHub Pages affichera `index.html` automatiquement.

Tant que les fichiers ne sont pas déposés, le site affiche des couvertures illustrées de remplacement et le bouton PDF explique où placer le document.

## Personnalisation rapide

- Couleurs principales : en haut de `style.css`, dans `:root`.
- Titres et textes : dans `index.html`.
- Chaque carte album est repérable par son numéro de tome.
